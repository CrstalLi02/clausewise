# Clausewise Source Delivery Package

This delivery package contains the complete source code, design materials, sample department files, tests, evaluation set, and Docker/Kubernetes/Helm deployment files.

## Included

- `backend/`: FastAPI control plane, facts/memory, RAG, Loop, tests, and scripts
- `services/pi-agent/`: pi Agent Runtime source code and npm lock file
- `web/`: Next.js frontend source code and npm lock file
- `deploy/`: Docker, Kubernetes, Helm, HPA, and monitoring configuration
- `department_files/`: Sample department PDF/DOCX files shipped with the project
- `design_files/`: Technical design, code walkthrough, reference PDFs, and architecture images
- `docs/`, `loadtest/`: Documentation and k6 load-test scripts
- `.env.example`, `services/pi-agent/.env.example`: Configuration templates without real secrets
- `design_files/Clausewise-Frontend-User-Guide.md`: Step-by-step instructions for students, department admins, and super admins

## Not Included (all can be regenerated)

- Python virtual environments: `backend/.venv/`, `venv/`
- Node dependencies: `node_modules/`
- Next.js/TypeScript build output: `.next/`, `dist/`, `build/`, `out/`, `*.tsbuildinfo`
- Test and language caches: `__pycache__/`, `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`
- Local runtime data and caches: `data/`, `volumes/`, `chroma_data/`, `.cache/`, logs
- Local real configuration: `.env`, `.env.local`, private keys, and certificates
- macOS/IDE files: `.DS_Store`, `.idea/`, `.vscode/`
- Delivery ZIPs and checksum files previously generated by this project: `clausewise-project-source-*.zip*`

## Quick Start for Recipients

### Docker

```bash
cp .env.example .env
# Edit .env and fill in the model API keys, database passwords, and internal service token
docker compose up --build -d
docker compose exec backend python -m scripts.seed_data
docker compose exec backend python -m scripts.ingest_department_files --base /app/department_files
```

### Installing Dependencies Locally

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cd ../web
npm ci

cd ../services/pi-agent
npm ci
```

For more details, see the root `README.md`, `docs/`, and each module's README.
